Anti-jobs

Keep Jev out of math, writing, and irreversible execution.

JobWho
Compute / determinismCode
Create prose, plans, draftsLLM
Decide next move at forksJev
Irreversible side effectsHuman Approve or pre-agreed policy

Illegal: Jev drafting the email. Jev issuing the refund. Jev merging the PR. Using Jev as a calculator.

page · apply-last-loop.md

Apply-last loop

assertLegalCommand → qualifyTask → gate → propose in memory → qualifyOutput → gate → applyCommand.

Apply is the first domain write and only after both gates GREEN, or human compose.

Illegal: apply then qualifyOutput; scoreFill as a live gate; TypeSafe on Temporal replay; jev-latest in production.

page · batch-decisions.md

Batch decisions

Ask every typed question that shares a snapshot in one POST. Then act once. Sequential Q1→mutate→Q2 pays latency per question and drifts state.

On this tape task pack and output pack are already batches. Do not split primitive-picker / fail-closed-gate / judge into three Activities.

page · benchmark-loop.md

Benchmark the whole loop

page · bounded-forks.md

Bounded forks

Put Jev at a fork whose options are a closed set. State → Choice + Score + Noul → route auto | review | block | escalate_human.

A fork with an open option set is an LLM job, not a Jev job.

page · c10-human-gate.md

C10 human gate

Complete, Trash, ResolveWaiting, send, and merge-to-default park on Signal humanVerdict {compose|escalate|refuse} even when the task gate is GREEN. Capture is the fast path. C10 is a Workflow park, not an Activity. The list is the contract in .jev/README.md; the three domain Commands are HUMAN_GATED_COMMANDS in src/domain.ts.

page · compose-answers.md

composeAnswers is code

TypeSafe returns an answer map. composeAnswers is deterministic code that turns that map into GREEN / AMBER / RED. Judge Choice cannot override a local RED. Mid-band noul on harness_can_branch demotes GREEN to AMBER.

page · confidence-routing.md

Confidence routing

Auto when confidence is high and Choice/Noul clears policy. Review in the mid-band. Block / human when low. Low confidence is not ask Jev again. It is AMBER / Signal.

page · context-screen.md

page · harness-vs-process.md

Harness loop vs business process

Same engine. Two clocks.

Harness occupancy (seconds): screen untrusted tool output; route skill/tool/model; groundedness. Goal is fewer LLM calls.

Process occupancy (hours to weeks): qualifyTask → propose → qualifyOutput → apply last; Waiting timer; C10 Signal. Goal is the write that cannot happen twice.

page · ormus-jev-lanes.md

Ormus Jev three lanes

Public Ormus doctrine names three places Jev is allowed to sit. They are not seats and not Temporal Workflows.

  1. Decision gate — before send / pay / merge / cancel.
  2. Claim verify — claim + evidence → verified | contradicted | unsupported.
  3. Context screen — untrusted text → pass | review | block | skip.

Code computes, LLMs create, Jev decides, humans approve irreversible side effects.

page · speed-contract.md

Speed contract

Skip the LLM when a typed question will do. Batch every question that shares a snapshot. Spend expensive compute only on a shortlist. Record the answer so a crash cannot pay for it again.

Ladder: code → one TypeSafe POST → LLM generate → Temporal park.

page · speed-first.md

Speed-first cut

Four speeds, cheapest first. Climb only when needed.

  1. Code — schema, amounts, dates.
  2. One TypeSafe POST — all independent questions together.
  3. Generator — only if Choice said needs prose or a patch.
  4. Temporal — only if the write must happen at most once, a human may take days, or a job must not rewind.

page · three-planes.md

Three planes

Three planes share a seam. They do not share a brain. Operad names questions. TypeSafe answers them. Temporal remembers the answer across crash, wait, and replay.

  • Operad / seats.ts owns question names.
  • TypeSafe owns one answer map per gate at pin jev-1.13.0.
  • Temporal owns Event History, Activity retry, Signal, timer, ContinueAsNew.

Operad must not fetch. TypeSafe must not apply. Temporal must not invent questions.
